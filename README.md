# Lumino

[English](./README_EN.md) | [中文](./README_ZH.md)

> Turn what you browse into what you build. · 将你浏览的一切，变为你构建的一切。

**Lumino** is a multi-modal AI assistant Chrome extension powered by your own LLM. It reads web pages, replicates designs, automates forms, manages files, and integrates with Obsidian — all while keeping your data private.

**Lumino** 是一款多模态 AI 助手 Chrome 扩展，使用你自己的 LLM 驱动。它能阅读网页、复刻设计、自动填写表单、管理文件，并与 Obsidian 笔记库集成——同时确保你的数据隐私。

## Installation · 安装

**Chrome Web Store** · [Download](https://chromewebstore.google.com/detail/lumino-browse-and-build-w/pgmojincedjeggjgfafpkbmloiiinplj) · 搜索 "Lumino"

**Manual** · 手动安装

```bash
git clone https://github.com/the-invulnus/lumino.git
cd lumino && pnpm install && pnpm build
```
